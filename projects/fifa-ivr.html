PROJECT 03 / SERVICE DESIGN × DATA ENGINEERING

FIFA IVR Case Study

A four-day interview case study using sample Interactive Voice Response data to assess system performance and identify opportunities to improve the customer experience.

View GitHub project ↗Explore Tableau dashboard ↗

THE CHALLENGE

Understand how the IVR was performing.

As part of an application for a Data Engineer role, I received sample FIFA IVR data and a four-day window to clean, analyze, and visualize it. The goal was to turn operational records into a concise view of call volume, handling patterns, language use, and system effectiveness.

THE APPROACH

Build a practical analysis pipeline.

I prepared the source files with a Python ETL workflow, loaded the data into PostgreSQL, and used SQL to examine trends across 2022 case management and 2023 ticket activity. Tableau presented key measures and comparisons.

  • Cleaned records, checked missing values, and standardized data types.
  • Examined IVR topics, source and language distributions, daily patterns, and year-over-year activity.
  • Compared system effectiveness and weekday versus weekend usage.

WHAT I FOUND

High usage—and room to improve coverage.

In the supplied sample, the IVR effectiveness rate was 84% in 2023, while usage was 78% higher than in 2022. English accounted for 76% of recorded IVR use; German represented 2%. Usage was also higher on weekdays than weekends. These observations informed recommendations to review language coverage, prepare for volume spikes, and consider support availability beyond weekdays.

The figures describe the provided case-study sample and should not be read as current FIFA operational metrics.
