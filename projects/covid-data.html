PROJECT 01 / PUBLIC HEALTH × DATA STORYTELLING

COVID-19 Data Exploration

A foundational data project exploring the global pandemic through SQL queries and a Tableau dashboard, with an emphasis on turning a large public dataset into clear comparisons.

View GitHub project ↗Explore Tableau dashboard ↗

THE QUESTION

How did the pandemic change over time and across places?

This first analytics project examined publicly available COVID-19 data to understand reported cases, deaths, vaccination progress, and differences between regions. It was an opportunity to practice core analysis methods and learn how to communicate findings visually.

THE APPROACH

Use SQL to find the shape of the data.

I used SQL to clean, combine, and explore the data, applying joins, common table expressions, temporary tables, window functions, aggregations, and views. The resulting queries informed Tableau charts covering global totals, population infection rates, comparisons by continent, and trends over time.

  • Compared reported cases, deaths, and population-based rates.
  • Reviewed changes over time and vaccination rollups.
  • Created visual summaries to make global and regional patterns easier to scan.

WHAT I LEARNED

Context matters as much as the headline.

The historical snapshot summarized roughly 775 million reported cases and 7 million reported deaths, or about a 0.9% ratio in the dataset. The dashboard also compares infection patterns by population and deaths by continent. These aggregate values depend on reporting, definitions, and the time period captured; they are descriptive and do not establish cause and effect.

This is a historical learning project based on public data. It is not a current public-health dashboard.
